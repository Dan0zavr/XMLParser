# XMLParser

XMLParser - это встраиваемая библиотека, предназначенная для автоматизации оформления docx документов. Предоставляет низкоуровневый интерфейс для работы с внутренней структурой документов (XML), что позволяет интегрировать её в различные проекты.

Библиотека предназначена для внутреннего использования.

## Основные возможности
* Задание шрифта
* Задание стиля абзацев
* Задание стиля таблиц
* Задание стиля рисунков
* Задание стиля списков

Каждый пункт применяется ко всему документу.
